# Interface direction

The household ledger should feel like a calm shared workspace. The distinctive surface is a single settlement worksheet with John and Blaire side by side: responsibility, money already contributed, personal advances, reimbursements, and the resulting transfer. Every amount stays connected to its explanation.

Palette: pine `#254f46`, pale sage `#e7efea`, slate `#263d38`, paper `#ffffff`, mist `#f5f7f6`, amber `#9b640f` for drafts. Typography: Georgia for the monthly heading, humanist Segoe UI for controls/body, tabular numerals for amounts. No remote font dependency.

Layout: narrow persistent navigation at desktop left, an open heading and month selector, a broad ledger next to the settlement worksheet. On phones navigation becomes a horizontal bar and ledger rows become readable cards. Left-aligned content, right-aligned currency. Borders separate accounting rows; cards are reserved for actual grouped calculations.

Review: avoid the generic grid of finance statistic tiles and decorative charts. Prioritize the actual task—understanding and closing a month. Use a quiet total-spending strip with pool breakdown instead of a dashboard hero. Preview data must be visibly labeled and kept separate from configured Firebase data.
